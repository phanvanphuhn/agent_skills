# Saved project contexts

Project discovery saves one Markdown PROJECT CONTEXT per target repository here. Use the
[template](../skills/project-discovery/references/project-context-template.md) for the
document structure. Name each file after the repository (for example, `checkout.md`);
if names collide, add a stable path-based qualifier. Record the exact target path and
Git baseline inside the file so future work can check freshness.

Update an existing file only when relevant facts change. Keep evidence references and
unknowns visible, and do not include secrets or copied private payloads. These files
are reusable project notes; task contracts and review reports stay in the conversation
unless the user asks to save them.
